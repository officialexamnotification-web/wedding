Contact Nimantran Royale for help with invitation templates, editing and sharing.

Need help using the invitation studio or have a question about a design? Send a note to our support team and include the page or feature you were using so we can understand the issue.

EMAIL SUPPORTsupport@invitationcards.site

Please do not email passwords, payment details or private guest lists.

Helpful details to include

  • The device and browser you are using
  • The invitation or feature name
  • A short description of what happened
  • A screenshot, if it helps explain the issue (hide personal details first)
